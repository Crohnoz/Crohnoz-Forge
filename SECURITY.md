# Security Policy

## Reporting a vulnerability

Do not publish suspected vulnerabilities in a public issue. Contact Crohnoz Labs privately with a concise description, reproduction steps, affected component, and potential impact.

## Current scope

This repository begins as a public demonstration environment using fictional data. No production credentials, personal data, client submissions, API keys, or secrets may be committed.

## Baseline rules

- Keep secrets in Netlify environment variables or an approved secret manager.
- Use least-privilege access.
- Review third-party integrations before activation.
- Treat idea submissions and attachments as private by default.
- Require explicit permission before publishing Forge Stories.
