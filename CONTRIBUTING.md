# Contributing

## Branches

- `main`: stable production branch.
- `develop`: integrated development branch.
- `feature/*`: isolated feature work.
- `deploy/*`: deployment preparation.

## Workflow

1. Branch from `develop`.
2. Keep commits focused and descriptive.
3. Never commit credentials or client data.
4. Test keyboard navigation, responsive layout, and the complete Forge flow.
5. Open a pull request with scope, screenshots, risks, and validation notes.
6. Merge only after review and successful deployment preview.

## Content rules

- Label fictional metrics and stories clearly.
- Distinguish client-reported outcomes from system-measured outcomes.
- Do not imply guarantees from exploratory indicators.
